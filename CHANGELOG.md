# Changelog

## 0.1.0 — 2026-10-15 (preview)

First curated Local Organiser backend preview, prepared from the private
application's existing development history.

- Inbox intake, projects/tasks, hierarchical contexts, knowledge and audit events.
- Explicit source ingestion with bounded text/PDF extraction and evidence-backed workspaces.
- Persisted context-action proposals with explicit review and application.
- Deterministic scheduling and optional CalDAV integration.
- Synthetic offline demo, isolated regression tests and maintained documentation.

The model benchmark and routing experiments remain planned. No model rankings or
measured cloud savings are claimed. See the [roadmap](docs/roadmap.md).
