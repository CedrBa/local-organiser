# Roadmap

This is the current direction, not a delivery-date commitment. Plans can change
with usage and evaluation. Release history belongs in [CHANGELOG](../CHANGELOG.md).

| Status | Milestone | Observable outcome |
|---|---|---|
| Implemented foundation | Backend and context workspace | Intake, sources, knowledge, tasks, evidence and explicit context-action application |
| 0.1.0 preview | Maintained backend | Reproducible setup/demo, clear docs and validated source snapshot |
| Planned | Organiser benchmark v1 | Versioned tasks, scoring rules and reproducible model comparisons |
| Planned | Small models and routing | Compare rules, fixed models and a small routing model at matched quality targets |
| Planned | Context queries and thin interface | Inspect context, evidence, tasks and proposals through a usable view |
| Planned | Task and planning extensions | Importance, hard/soft dates, remaining effort, fixed/flexible blocks and replanning |
| Planned | End-to-end evaluation | Measure quality, cloud usage, retries, latency and cost across complete workflows |
| Exploration | More sources and automation | Gmail, automatic scans and explicitly defined action permissions |

Evaluation grows with the product. A small model is not assumed to outperform rules.
Cloud escalation, watchers, OCR and broad retrieval remain later investigations.
A full assistant workflow should connect intake, knowledge, work, planning,
progress and replanning, as described by the [research direction](evaluation/benchmark-design.md).
